# デザイントークン — 追いつけEnglish

シリーズ第1弾「察してEnglish」（C:\Users\uenokengo\dev\taboo-english-game）からブランドを継承する。
配色・フォントは前作と完全に同一の値を使い、シリーズとして一目でわかることを最優先する。

## カラー

| トークン名 | 値 | 用途 |
|---|---|---|
| `navy` | `#18243a` | 背景（濃色パネル）、見出しテキスト、主要な文字色 |
| `cream` | `#fff9ee` | 画面全体の背景 |
| `creamCard` | `#fffdf7` | カード・パネルの背景（`cream`よりわずかに明るい） |
| `orange` | `#ff6f47` | アクセント、CTAボタン、強調要素、ロゴの"English"部分 |
| `yellow` | `#ffc83d` | 補助アクセント、ハイライト系の装飾 |
| `green` | `#3dae62` | 正解・成功・ポジティブなフィードバック |
| `hairline` | `#e8dcc0` | 枠線、区切り線、非アクティブな要素 |

ダークモード専用の配色は定義しない（前作もライト固定・`userInterfaceStyle: light`）。

## フォント

| トークン名 | フォント | 用途 |
|---|---|---|
| `display` | `Fredoka_700Bold` | 数字（スコア・タイマー）、英字の大きな強調表示 |
| `heading` | `MPLUSRounded1c_700Bold` | 日本語の見出し・ラベル・ボタン文言 |
| `bodyRegular` | `ZenKakuGothicNew_400Regular` | 日本語の本文・説明文 |
| `bodyBold` | `ZenKakuGothicNew_700Bold` | 日本語の強調本文 |

角丸で親しみやすいフォントの組み合わせを維持する。フォールバックはシステムフォントとする。

## 形状・質感

- 角丸（`borderRadius`）を多用し、カードは16〜24px、ボタンやバッジは9999px（ピル型）を基本とする
- 主要な枠線は太め（2〜2.5px）の`navy`または`orange`で、輪郭のはっきりしたポップな印象を作る
- 影は最小限（フラットで彩度の高い配色そのものでメリハリをつける前作のスタイルを踏襲）

## マスコットの方向性

前作と同じ「丸顔・黒目二つ」のミニマルなフェイスアイコンをベースに、本作は**音読・発声がテーマ**であるため以下の表情アレンジとする。

- 口を大きく開けて声を出している表情（前作は口を閉じて歯を見せる程度だったのに対し、本作はより開いた口で「読み上げている最中」を表現）
- 口の周りやフェイスの外側に、声や音を表す簡単な装飾（音符・波線・スピーカーアイコン風のモチーフなど）を添えてもよい
- 色は前作と同じ`cream`の顔に`orange`の口という配色を基本にする
