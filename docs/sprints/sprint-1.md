## Sprint 1: コアゲームループ ―「流れる英文に追いつく」が1台で遊べる状態にする

### ゴール

1台の端末で、ゲーム開始からリザルト表示まで**中断なく最後まで遊べる**こと。本作の中核である「説明文が単語数に応じた速度で流れる」演出が実際に手触りとして確認でき、プレイテストで速度パラメータの妥当性を判断できる状態にする。

---

### スコープ判断の理由

**Sprint 1 に含めるもの**

| 含めるもの | 理由 |
|---|---|
| モノレポ基盤（Expo + expo-router + `packages/game-core`） | リポジトリがほぼ空のため、最低限の骨格がなければ何も動かせない。前作と同一構成にする制約があるため、最初に確定させる |
| 流れる説明文演出 | **本作で唯一まだ検証されていないメカニクス**。速度が速すぎれば遊べず、遅すぎれば緊張感がない。ゲームとして成立するかがここで決まるため、最優先で実物を触れる状態にする |
| 無料スターターパック（お題データ） | 演出の検証には実際の英文が必要。単語数のばらつき（短文/長文）を含むデータがないと速度計算を評価できない |
| コアゲームループ（タイムアタック + CORRECT/SKIP + リザルト） | 「1ゲーム遊べる」の最小単位。ここまで通して初めてプレイテストが可能になる |

**Sprint 1 から外すもの**

| 外すもの | 理由 |
|---|---|
| IAP課金 / RevenueCat連携 / ストア画面 | 実機のDev Buildとストアコンソール側の商品登録が前提で、Expo Goやブラウザでは検証できない。コアメカニクスが「面白い」と確認できる前に課金基盤へ投資するのはリスクが高い。Sprint 3 に集約する |
| 複数テーマパックの管理・パック選択UI | パックが1つしかない Sprint 1 では選択UIが無意味。パック追加は課金と同時（Sprint 3）に行うのが自然 |
| リプレイ機能（前作のヒント相当） | 救済措置は「素の難易度」を体感してから設計すべき。速度パラメータが確定していない段階で作ると作り直しになる |
| ホーム / 遊び方 の作り込み、レビュー訴求 | Sprint 1 ではプレイ画面に到達できる最小限の導線があれば足りる。画面の作り込みは Sprint 2 |
| アイコン・スプラッシュ・ストア公開物 | リリース準備は Sprint 4 |

**制限時間の選択（1分/3分/5分）は Sprint 1 に含める**。タイムアタックの長さはゲームの印象を大きく変えるため、プレイテストで比較できる必要がある。

---

### 実装する機能

- **機能A: モノレポ基盤とアプリ骨格**
  npm workspaces（`apps/*`, `packages/*`）構成で Expo + expo-router のモバイルアプリを立ち上げ、ゲームロジックを `packages/game-core` に分離する。ブランドフォント（Fredoka / M PLUS Rounded 1c / Zen Kaku Gothic New）を読み込み、`/` → `/start` → `/play` の画面遷移を通す。前作 `taboo-english-game` と同一のディレクトリ構成・依存構成に揃える。

- **機能B: お題カードのデータモデルと無料スターターパック**
  「お題単語（日本語 / English）」と「英語の説明文」を持つカード型を定義し、無料スターターパックとして30問を用意する。説明文にはお題の英単語そのものを含めない。8語程度の短文から20語程度の長文までを意図的に混在させる。

- **機能C: 流れる説明文演出（本作の中核）**
  説明文の単語数からフロー時間を自動計算し（`LEAD_IN 1000ms + 単語数 × MS_PER_WORD`、下限4000ms）、説明文全体を画面下から上へ、平面のまま一定速度でスクロールアップさせる（単語単位のハイライト表示は行わない。3D遠近法は実機確認の結果、可読性を損なうためユーザー判断で廃止し平面スクロールに変更）。スクロール完了後は3秒の猶予を経て自動的に次のお題へ進む。
  **スタート設定画面で「簡単/普通/難しい」の3段階からスクロール速度を選べる**（ユーザー追加要望）。`MS_PER_WORD` は 簡単=900ms / 普通=650ms（デフォルト） / 難しい=480ms とする（初期値から実プレイのフィードバックを受け3回にわたり段階的に減速済み）。選択値はゲーム開始時に固定し、プレイ中は変更しない。

- **機能D: コアゲームループとリザルト**
  「3・2・1・GO!」のカウントダウン後、全体タイムアタック（1分 / 3分 / 5分から選択）を開始する。「✓ CORRECT!」で +1点して次のお題へ、「SKIP」で加点なしで次のお題へ。全体タイマーが0になったらリザルト画面にスコア・正解数・スキップ数を表示する。

### スプリント契約（完了条件）

以下の全条件を満たした場合のみ、このスプリントは完了とする。

**基盤・起動**

- [ ] リポジトリルートで `npm install` が成功し、`apps/mobile` と `packages/game-core` が npm workspaces として認識される
- [ ] `apps/mobile` をブラウザ（Expo Web）で起動でき、ホーム画面が表示される。起動時にコンソールエラーが出ない
- [ ] ホーム画面の「GAME START」をタップするとスタート設定画面に遷移し、そこから「START」をタップするとプレイ画面に遷移する
- [ ] 画面上の英数字が Fredoka、日本語見出しが M PLUS Rounded 1c、日本語本文が Zen Kaku Gothic New で表示される（デフォルトのシステムフォントのままになっていない）

**お題データ**

- [ ] 無料スターターパックに30問以上のお題カードが存在し、各カードが「お題単語」と「英語の説明文」を持つ
- [ ] すべての説明文が8語以上20語以下であり、10語未満の短文と16語以上の長文がそれぞれ3問以上含まれている
- [ ] どの説明文にも、そのお題の英単語（および単純な複数形・活用形）が含まれていない

**流れる説明文演出**

- [ ] プレイ画面に、お題単語と英語の説明文の両方が表示される
- [ ] カウントダウン終了後、説明文全体が画面下から上へ向かって平面のままスクロールアップを開始する（単語単位のハイライト表示は行わない。傾き・縮小・遠近感は付けない）
- [ ] 説明文の単語数が多いカードほどスクロールの総所要時間が長くなる（12語のカードと20語のカードで所要時間が明確に異なることを計測して確認できる）
- [ ] スクロールが完了してから3秒間は、そのお題のまま「✓ CORRECT!」と「SKIP」が押せる
- [ ] スクロール完了から3秒経過しても操作がない場合、自動的に次のお題へ進む。このとき得点は加算されず、リザルトのスキップ数が1増える
- [ ] 新しいお題に切り替わるたび、スクロールが画面下端からやり直される

**流れる説明文演出（速度選択）**

- [ ] スタート設定画面で「簡単 / 普通 / 難しい」の3段階からスクロール速度を選択できる（デフォルトは「普通」）
- [ ] 「簡単」を選んだ場合、同じ単語数のカードでも「普通」より明確にスクロール所要時間が長くなる
- [ ] 「難しい」を選んだ場合、同じ単語数のカードでも「普通」より明確にスクロール所要時間が短くなる
- [ ] ゲーム開始後（プレイ画面表示後）は速度選択を変更する手段がなく、選択時の速度がゲーム終了まで一貫して適用される

**ゲームループ・リザルト**

- [ ] スタート設定画面で 1分 / 3分 / 5分 を選択でき、選択した長さが全体タイマーの初期値としてプレイ画面に反映される
- [ ] プレイ画面の冒頭で「3 → 2 → 1」のカウントダウンが表示され、0になるまで全体タイマーとハイライトが進行しない
- [ ] プレイ中は画面上に現在のスコアと残り時間が常時表示され、残り時間が1秒ごとに減る
- [ ] 「✓ CORRECT!」をタップするとスコアが1増え、次のお題に切り替わる
- [ ] 「SKIP」をタップするとスコアは変わらず、次のお題に切り替わる
- [ ] 「✓ CORRECT!」を素早く連打しても、1回のタップにつきスコアの加算は1回だけであり、お題が2枚以上飛ばされない
- [ ] 同一ゲーム内で、パック内のカードを使い切るまで同じお題が2回出題されない
- [ ] 全体タイマーが0になると、操作の有無にかかわらずリザルト画面に切り替わる
- [ ] リザルト画面に、最終スコア・正解数・スキップ数の3つが数値で表示される
- [ ] リザルト画面の「HOME」をタップするとホーム画面に戻り、再度「GAME START」からスコア0の新しいゲームを開始できる

**堅牢性**

- [ ] プレイ画面から途中でホームに戻り、すぐに新しいゲームを開始しても、前回のスコア・残り時間・スクロール状態が引き継がれない
- [ ] 幅375pxのビューポートで、お題単語・説明文・両ボタンがすべて画面内に収まり、横スクロールが発生しない
